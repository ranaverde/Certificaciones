⚡ Apache Spark Fundamentals

Conceptos Clave de Spark

  • RDD: Resilient Distributed Dataset - abstracción fundamental
  • DataFrame: Colección distribuida de datos organizados en columnas
  • Dataset: API type-safe (Scala/Java)
  • Transformations: Operaciones lazy (map, filter, select)
  • Actions: Operaciones que devuelven resultados (collect, count, show)
💡 Concepto Clave: Spark usa evaluación perezosa (lazy evaluation) - las transformaciones no se ejecutan hasta que se llama a una acción.

Ejercicio 1: DataFrames Básicos

# Leer un archivo CSV
df = spark.read.format("csv") \
    .option("header", "true") \
    .option("inferSchema", "true") \
    .load("/path/to/data.csv")

# Transformaciones básicas
df_filtered = df.filter(df.age > 18) \
    .select("name", "age", "city")

# Mostrar resultados
df_filtered.show()

🔄 ETL con Databricks

Patrones ETL Comunes

  • Bronze Layer: Datos raw/sin procesar
  • Silver Layer: Datos limpios y validados
  • Gold Layer: Datos agregados para análisis
  • Medallion Architecture: Arquitectura de capas

Ejercicio 3: Pipeline ETL Medallion

# Bronze: Ingestar datos raw
bronze_df = spark.read.json("/raw/events") \
    .withColumn("ingestion_time", current_timestamp())

bronze_df.write.format("delta") \
    .mode("append") \
    .save("/delta/bronze/events")

# Silver: Limpiar y transformar
from pyspark.sql.functions import col, to_date

silver_df = spark.read.format("delta") \
    .load("/delta/bronze/events") \
    .filter(col("event_type").isNotNull()) \
    .withColumn("event_date", to_date(col("timestamp")))

silver_df.write.format("delta") \
    .mode("overwrite") \
    .save("/delta/silver/events")

# Gold: Agregar para analytics
gold_df = silver_df.groupBy("event_date", "event_type") \
    .agg(count("*").alias("event_count"))

gold_df.write.format("delta") \
    .mode("overwrite") \
    .save("/delta/gold/event_summary")

🔀 Operaciones MERGE (Upsert)

MERGE en Delta Lake

  • Combinar INSERT, UPDATE y DELETE en una operación
  • Fundamental para CDC (Change Data Capture)
  • Operación atómica y eficiente

Ejercicio 4: MERGE Operation

from delta.tables import DeltaTable
from pyspark.sql.functions import col

# Cargar tabla existente
target = DeltaTable.forPath(spark, "/delta/customers")

# Nuevos datos o actualizaciones
updates_df = spark.read.format("csv") \
    .option("header", "true") \
    .load("/updates/customers_new.csv")

# Realizar MERGE
target.alias("target") \
    .merge(
        updates_df.alias("updates"),
        "target.customer_id = updates.customer_id"
    ) \
    .whenMatchedUpdate(set = {
        "name": col("updates.name"),
        "email": col("updates.email"),
        "updated_at": current_timestamp()
    }) \
    .whenNotMatchedInsert(values = {
        "customer_id": col("updates.customer_id"),
        "name": col("updates.name"),
        "email": col("updates.email"),
        "created_at": current_timestamp()
    }) \
    .execute()

Ejercicio 5: Auto Loader

# Auto Loader para streaming incremental
streaming_df = spark.readStream \
    .format("cloudFiles") \
    .option("cloudFiles.format", "json") \
    .option("cloudFiles.schemaLocation", "/schemas/events") \
    .load("/incoming/events")

# Procesar y escribir
query = streaming_df.writeStream \
    .format("delta") \
    .outputMode("append") \
    .option("checkpointLocation", "/checkpoints/events") \
    .start("/delta/bronze/events")

query.awaitTermination()

🚀 Optimización de Performance

Técnicas de Optimización

  • Z-Ordering: Organizar datos para queries rápidas
  • OPTIMIZE: Compactar archivos pequeños
  • VACUUM: Limpiar archivos antiguos
  • Partitioning: Particionar datos grandes

Ejercicio 6: Optimización de Delta Tables

# Optimizar tabla
spark.sql("OPTIMIZE delta.`/delta/events`")

# Z-Order por columnas frecuentemente filtradas
spark.sql("""
    OPTIMIZE delta.`/delta/events`
    ZORDER BY (event_date, user_id)
""")

# Limpiar archivos viejos (retener 7 días)
spark.sql("""
    VACUUM delta.`/delta/events` 
    RETAIN 168 HOURS
""")
