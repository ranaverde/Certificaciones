📐 Arquitectura de Snowflake

Capas de Arquitectura

  • Database Storage: Almacenamiento de datos optimizado y comprimido
  • Query Processing: Virtual warehouses para procesamiento de consultas
  • Cloud Services: Gestión de metadata, seguridad, y optimización
💡 Concepto Clave: Snowflake separa el almacenamiento del cómputo, permitiendo escalar cada uno independientemente.

Ejercicio 1: Crear tu primer Warehouse

-- Crear un warehouse
CREATE WAREHOUSE my_warehouse
  WITH WAREHOUSE_SIZE = 'SMALL'
  AUTO_SUSPEND = 300
  AUTO_RESUME = TRUE;

-- Usar el warehouse
USE WAREHOUSE my_warehouse;

🗄️ Gestión de Datos

Tipos de Tablas

  • Permanent Tables: Almacenamiento persistente con Time Travel
  • Temporary Tables: Vida útil de la sesión
  • Transient Tables: Sin Fail-safe, menor costo
  • External Tables: Datos en almacenamiento externo

Ejercicio 2: Trabajar con Tablas

-- Crear una tabla permanente
CREATE OR REPLACE TABLE customers (
    customer_id INT,
    name VARCHAR(100),
    email VARCHAR(100),
    created_date DATE
);

-- Cargar datos desde un archivo
COPY INTO customers
FROM @my_stage/customers.csv
FILE_FORMAT = (TYPE = 'CSV' SKIP_HEADER = 1);

⏰ Time Travel y Fail-safe

Time Travel

  • Recuperar datos históricos hasta 90 días (Enterprise)
  • Standard edition: hasta 1 día
  • Usar AT o BEFORE para consultas históricas

Ejercicio 3: Time Travel

-- Ver datos de hace 5 minutos
SELECT * FROM customers
AT(OFFSET => -60*5);

-- Restaurar una tabla eliminada
UNDROP TABLE customers;

-- Clonar una tabla en un punto específico del tiempo
CREATE TABLE customers_backup CLONE customers
AT(TIMESTAMP => '2024-01-01 00:00:00'::timestamp);

⚡ Optimización de Rendimiento

Clustering Keys

  • Mejorar el rendimiento de consultas en tablas grandes
  • Elegir columnas frecuentemente filtradas
  • Monitorear con SYSTEM$CLUSTERING_INFORMATION

Ejercicio 4: Clustering

-- Agregar clustering key
ALTER TABLE large_table
CLUSTER BY (date_column, region);

-- Verificar clustering
SELECT SYSTEM$CLUSTERING_INFORMATION('large_table');

🔒 Seguridad y Gobernanza

Control de Acceso

  • Roles: Sistema basado en roles (RBAC)
  • Users: Identidades de usuario
  • Grants: Permisos explícitos
  • Network Policies: Control de acceso por IP

Ejercicio 5: Gestión de Roles

-- Crear un rol
CREATE ROLE data_analyst;

-- Otorgar permisos
GRANT USAGE ON WAREHOUSE analytics_wh TO ROLE data_analyst;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO ROLE data_analyst;

-- Asignar rol a usuario
GRANT ROLE data_analyst TO USER john_doe;
